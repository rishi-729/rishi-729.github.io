Intelligent LLM Router

A token-optimizing router that sits in front of any LLM workload and sends each prompt to the cheapest model capable of handling it — scoring difficulty before routing, and layering in semantic caching so repeated or near-duplicate prompts never hit a paid model twice. The goal: cut token spend without cutting output quality.

LLM Routing Semantic Caching Cost Optimization Model Evaluation
  • Difficulty-based routing: classify prompt complexity, then send simple requests to cheap/fast models and reserve expensive models for what actually needs them.
  • Semantic cache: catch near-duplicate prompts before they trigger a new (billable) model call.
  • Designed to pair with the self-hosted Raspberry Pi tier below as a free "cheapest possible" routing target.

Raspberry Pi Self-Hosted LLM

Running a local, open-source LLM on a Raspberry Pi to serve as the free "cheap tier" for the router above — handling the simplest, lowest-stakes prompts entirely on-device with zero API cost, before anything more complex gets escalated to a larger hosted model.
